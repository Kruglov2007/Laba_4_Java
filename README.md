# Построение графиков функций на основе подготовленных файлов

Учебное графическое Java-приложение (на базе библиотеки **Java Swing**), предназначенное для считывания бинарных файлов координат и их последующей визуализации в виде двухмерных графиков математических функций.

Проект разработан в рамках лабораторной работы и полностью реализует требования **Варианта №3**.

## 🚀 Реализованный функционал (Вариант №3)

* **Линия графика (а):** Кастомное начертание в виде сложной штрихпунктирной линии с динамическим шагом, реализованное через конфигурацию массива паттернов в классе `BasicStroke`.
* **Стилизация маркеров (а):** В точках пересечения координат отрисовываются маркеры в виде круга с перекрестием внутри ($\oplus$) фиксированного размера $11 \times 11$ пикселей.
* **Специальное условие (б):** Реализован алгоритм проверки чётности целой части значения функции ($Y$) в точке. Маркеры, удовлетворяющие условию, автоматически окрашиваются в **синий цвет**, остальные остаются **красными**.
* **Дополнительные элементы отображения (в):** 
  * Точка начала координат $(0,0)$ наглядно обозначается на холсте зелёным маркером.
  * Крайние границы координатной сетки (`minX`, `maxX`, `minY`, `maxY`) автоматически рассчитываются и подписываются на соответствующих осях.
  * Добавлен новый пункт в меню «График», позволяющий динамически включать или отключать отображение этих отметок.
* **Оптимизация структуры данных:** Внедрена автоматическая сортировка входного массива точек по возрастанию абсциссы ($X$) перед отрисовкой, что предотвращает появление ломаных петель при чтении неотсортированных файлов.

## 🛠 Архитектура проекта

Проект разделён на два основных класса:
1. `Main.java` — главное окно приложения (`JFrame`), отвечающее за формирование структуры главного меню («Файл», «График»), обработку пользовательских событий и поблочное бинарное чтение данных через поток `DataInputStream`.
2. `GraphicsDisplay.java` — кастомный компонент отображения (`JPanel`), содержащий всю графическую логику вычисления масштаба, трансформации координат и непосредственного рисования элементов на двумерном холсте `Graphics2D`.

## 📂 Формат входных данных

Приложение считывает файлы в бинарном формате. Структура данных представляет собой непрерывный поток чисел с плавающей точкой двойной точности (`Double`), идущих строго чередующимися парами:
$$X_1, Y_1, X_2, Y_2, \dots, X_n, Y_n$$

## 💻 Требования для запуска

* **Java Development Kit (JDK):** Версия 8 или выше.
* **Среда разработки (опционально):** IntelliJ IDEA, Eclipse или NetBeans.
