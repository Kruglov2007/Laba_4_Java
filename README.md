# Лабораторная работа №5: Обработка событий мыши и масштабирование графиков

Учебное интерактивное графическое приложение на базе библиотеки **Java Swing (AWT)**, предназначенное для визуализации двухмерных графиков математических функций по точкам, считанным из бинарных файлов. 

Проект расширяет возможности базовой отрисовки графиков и полностью реализует требования **Варианта №3 (Вариант B)** по обработке пользовательских событий от мыши.

---

## 🚀 Реализованный функционал (Вариант B)

В приложении реализован полный набор интерактивных инструментов для исследования графиков функций:

1. **Динамическое отображение координат (Hit Test):**
   * При перемещении курсора мыши над холстом система непрерывно рассчитывает расстояние до маркеров точек.
   * Если курсор оказывается в радиусе маркера, точка подсвечивается **бирюзовым цветом (Color.CYAN)**.
   * Рядом с курсором всплывает кастомная подсказка (*Tooltip*) желтоватого цвета, отображающая точные математические координаты точки в формате `X: %.2f, Y: %.2f`.
   * При уходе курсора с маркера или за пределы панели подсказка автоматически скрывается, а маркер возвращает свой исходный цвет.

2. **Масштабирование фрагментов графика (Zoom):**
   * Пользователь может приблизить любой фрагмент графика, зажав левую кнопку мыши в верхнем левом углу целевой области и протянув ее к правому нижнему углу.
   * Во время перетаскивания область выделения визуально отображается в виде динамической **черной пунктирной рамки фокуса**.
   * При отпускании левой кнопки мыши выбранная область плавно растягивается и распахивается на весь экран.

3. **Восстановление исходного масштаба (Reset Zoom):**
   * Нажатие **правой кнопки мыши** в любой области холста мгновенно сбрасывает все текущие уровни приближения и возвращает график к первоначальному масштабу.

4. **Базовая визуализация (из ЛР №4):**
   * Отрисовка графика сложным штрихпунктирным пером (красный цвет).
   * Выделение маркеров точек окружностями размера $11 \times 11$ пикселей с перекрестием.
   * Автоматическое окрашивание маркеров в **синий цвет**, если целая часть значения функции $Y$ четная, и в **красный** — во всех остальных случаях.
   * Отрисовка осей координат, подписей экстремумов сетки и выделение начала координат `(0,0)` зеленым маркером.

## 🛠 Математическое обеспечение и геометрия проецирования

Ключевая сложность работы заключается в синхронизации двух принципиально разных систем координат: декартовой (математической, где ось $Y$ направлена вверх) и экранной (пиксельной, где начало координат находится в левом верхнем углу, а ось $Y$ направлена вниз).

* **Прямое преобразование координат (`xyToPoint`):**
  Переводит математические абстрактные значения $(x, y)$ из файла в физические пиксели на экране $(X, Y)$ для отрисовки графических примитивов:
  $$X_{\text{экран}} = (x - \min X) \times \text{scale}$$
  $$Y_{\text{экран}} = (\max Y - y) \times \text{scale}$$

* **Обратное преобразование координат (`pointToXY`):**
  Используется при выделении области рамкой. Переводит экранные пиксели клика мыши $(X, Y)$ обратно в математические границы декартова пространства:
  $$x_{\text{мат}} = \min X + \left(\frac{X_{\text{экран}}}{\text{scale}}\right)$$
  $$y_{\text{мат}} = \max Y - \left(\frac{Y_{\text{экран}}}{\text{scale}}\right)$$

* **Алгоритм проверки попадания (Hit Test):**
  Поскольку пиксель мыши не может идеально совпасть с пикселем центра маркера, попадание рассчитывается по теореме Пифагора (расстояние между двумя точками на плоскости):
  $$d = \sqrt{(X_{\text{курсора}} - X_{\text{маркера}})^2 + (Y_{\text{курсора}} - Y_{\text{маркера}})^2}$$
  Если расстояние $d \le \frac{\text{pointRadius}}{2} + 4$, фиксируется наведение на точку.

## 📂 Архитектура и программные компоненты

Проект реализован с использованием **делегационной модели обработки событий** и паттерна **«Адаптер»**:

* **`Main.java`:** Главный оконный каркас приложения (`JFrame`). Отвечает за построение главного меню («Файл», «График»), управление доступностью пунктов меню в зависимости от наличия данных (`GraphicsMenuListener`) и поблочное бинарное чтение пар координат типа `Double` из файлов с помощью `DataInputStream`. Перед отправкой данных на отрисовку выполняет их обязательную сортировку по возрастанию абсциссы $X$.
* **`GraphicsDisplay.java`:** Кастомный графический компонент (`JPanel`). Содержит всю математику расчетов масштаба и отрисовки.
  * Внутри конструктора создается единый объект `MouseAdapter`, который переопределяет методы `mousePressed()`, `mouseDragged()`, `mouseReleased()`, `mouseMoved()` и `mouseExited()`.
  * Объект регистрируется одновременно через методы `addMouseListener()` и `addMouseMotionListener()`.
  * Флаг `isDataLoaded` работает как триггер-защелка, гарантируя, что исходные экстремумы графика будут сохранены в переменные `originalMinX` (и др.) строго один раз при первой отрисовке, предотвращая их затирание во время зума при промежуточных вызовах `repaint()`.

---

## 📂 Формат входных бинарных данных

Приложение работает с файлами, содержащими непрерывную последовательность чисел с плавающей точкой двойной точности (`Double`). Каждые два числа подряд интерпретируются как единая точка на плоскости:
$$X_1, Y_1, X_2, Y_2, \dots, X_n, Y_n$$
